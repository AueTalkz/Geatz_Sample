# Itz Geatz Website Vibe Coding Prompt

## Project Overview

Build a fully responsive, modern, aesthetic website for my personal
brand and creative studio **"Itz Geatz"**.

The website should represent a futuristic creator-focused digital brand
that combines:

-   Content Creation
-   Video Editing
-   Creative Strategy
-   Digital Storytelling
-   A growing creator community called **"Geeks"**

The website should communicate:

> "A place where creators grow, people connect, and ideas become
> reality."

## Brand Personality

-   Creative
-   Ambitious
-   Youthful
-   Innovative
-   Community Driven

The website should feel like a premium creator economy startup, not a
generic freelancer portfolio.

Create a:

-   Premium creator-focused aesthetic
-   Dark cinematic theme
-   Modern startup landing page style
-   Minimal but visually impactful layout
